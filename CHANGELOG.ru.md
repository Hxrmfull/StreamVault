# История изменений

[English](CHANGELOG.md) · **Русский**

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## Ещё не выпущено

### Изменено

- **Библиотека:** щелчок по карточке открывает запись в проигрывателе
  программы с чатом, значок «играть» на карточке — в проигрывателе Windows.
- **Выпадающие списки** рисует сама программа, а не Windows: ровные
  стрелки, список в стиле окна с галочкой у выбранного, плавное появление,
  открытие вверх, если внизу нет места. Клавиатура работает как раньше.

### Исправлено

- **Просмотр записи YouTube в окне** — идущей или оставленной в `.ts` —
  останавливался с ошибкой декодирования: в низком качестве у YouTube звук
  HE-AAC, и поток сообщал проигрывателю неверные параметры звука.
- **Просмотр записи, которая ещё пишется,** начинается за пару секунд на
  всех площадках. У YouTube первый кадр приходил через 10–15 с,
  проигрыватель не дожидался и запрашивал поток заново по кругу.

## 0.1.1 — 2026-10-31

### Добавлено

- **Установщик** `StreamVault-<версия>-setup.exe`: выбор папки, ярлыки
  в меню «Пуск» и на рабочем столе, удаление через параметры Windows.
  Ставит для текущего пользователя без прав администратора или для всех.
  Установленная копия обновляется сама: скачивает и запускает новый
  установщик.

### Исправлено

- Окно не открывалось, если архив распаковать Проводником: Windows
  помечает каждый распакованный файл как скачанный из интернета, и .NET
  отказывался грузить библиотеку окна. Теперь программа при запуске снимает
  эту пометку со своих файлов.

## 0.1.0 — 2026-10-31

Первая открытая версия.

### Добавлено

- **Запись эфиров** Twitch, Kick, YouTube и VK Video Live: кнопка «Начать
  запись» или автозапись, свои настройки записи у канала, продолжение
  новой частью после обрыва, конвертация в MP4 без перекодирования и
  деление на куски.
- **Запись с начала эфира:** кусок до начала записи скачивается из записи
  эфира на площадке.
- **Чат эфира** всех четырёх площадок рядом с записью; чат записей и клипов
  в HTML, JSON или видео чата.
- **Загрузки** записей, хайлайтов и клипов: выбор качества, отрезки,
  «Скачать всё», продолжение после перезапуска.
- **Поиск каналов** сразу на всех четырёх площадках, аватарки и кадры
  идущих эфиров.
- **Библиотека и проигрыватель** с чатом в такт видео, продолжением с места,
  горячими клавишами, просмотром идущей записи, клипами и чатом поверх
  видео.
- **Защита места на диске**, срок хранения записей и проверка на пропуски.
- Трей, уведомления, запуск вместе с Windows, русский и английский
  интерфейс, обновления из релизов GitHub и обновление yt-dlp из окна.
